# 🚀 Entre Help

### AI-Driven Scheme Matching, Concessional Finance Advisory & Bankable DPR Generator for Marginalized Entrepreneurs

> **Mission**: Empowering Scheduled Castes (**SC**), Scheduled Tribes (**ST**), Other Backward Classes (**OBC**), Persons with Disabilities (**PwD**), and **Women** entrepreneurs to navigate government subsidies, verify eligibility, generate bank-ready Detailed Project Reports (DPR), and connect with authorized channel partners.

---

## 🌟 Executive Summary & Platform Overview

**Entre Help** is an end-to-end, production-grade financial inclusion and decision support platform engineered to bridge the implementation gap in affirmative entrepreneurship schemes in India. 

Every year, thousands of crores allocated under central and state affirmative financing programs—such as **MoSJE** (Ministry of Social Justice and Empowerment), **NSFDC**, **NBCFDC**, **NSTFDC**, **NHFDC**, **Stand-Up India**, **PMEGP**, and **PM Mudra Yojana**—remain underutilized. Grassroots entrepreneurs frequently encounter insurmountable hurdles:
- **Informational Asymmetry**: Obscure eligibility criteria buried across hundreds of fragmented PDF circulars.
- **Credit Application Rejections**: Over 65% of loan applications are rejected by commercial banks due to missing documentation, ineligible project cost ratios, or incorrect promoter equity.
- **The DPR Cost Barrier**: Private financial consultants charge ₹5,000 to ₹25,000 to draft a Detailed Project Report (DPR), creating an upfront financial barrier for micro-entrepreneurs.
- **Channel Financing Confusion**: Applicants do not know whether to apply via State Channelizing Agencies (SCAs), Public Sector Banks (PSBs), or Regional Rural Banks (RRBs).

**Entre Help** eliminates these barriers through an integrated, user-centric suite: **Smart Scheme Recommendation**, **Side-by-Side Scheme Comparison**, **Application Document Auditing**, **Automated Bankable DPR Generation with 1-Click PDF Export**, **Concessional EMI & Margin Money Calculation**, and **Authorized Channel Partner Routing**.

## 🚀 Key Modules & Capabilities

### 1. 🏛️ Smart Scheme Recommender
- Comprehensive database of **44+ verified Central and State government schemes** spanning affirmative action corporations and MSME programs:
  - **NSFDC** (National Scheduled Castes Finance and Development Corporation)
  - **NBCFDC** (National Backward Classes Finance & Development Corporation)
  - **NSTFDC** (National Scheduled Tribes Finance and Development Corporation)
  - **NHFDC** (National Divyangjan Finance and Development Corporation)
  - **Stand-Up India** (Greenfield enterprises for SC/ST and Women)
  - **PMEGP** (Prime Minister’s Employment Generation Programme with up to 35% subsidy)
  - **PM Mudra Yojana** (Shishu, Kishore, Tarun concessional loans)
  - **CGTMSE** (Credit Guarantee Fund Trust for Micro and Small Enterprises)
- **Profile-Driven Match Score**: Dynamically scores compatibility (0% - 100%) against social category, annual family income, enterprise sector, urban/rural location, and project cost.
- Direct links to official portals (**JanSamarth**, **Stand-Up Mitra**, and state nodal portals).

### 2. ⚖️ Side-by-Side Scheme Compare Engine
- Allows entrepreneurs and counselors to compare schemes side-by-side.
- Evaluates:
  - **Maximum Project Cost / Loan Ceiling** (from ₹50,000 micro-credit up to ₹5 Crores)
  - **Concessional Interest Rates** (down to 4% - 6% p.a.)
  - **Capital Subsidy Quantum** (e.g., 15% to 35% margin subsidy)
  - **Promoter Equity Requirement** (statutory 5% to 15% contribution)
  - **Moratorium & Repayment Tenures** (up to 10 years including gestation periods)
  - **Collateral / Third-Party Guarantee Waivers** under credit guarantee coverage.

### 3. 📋 Application Auditor & Readiness Score
- Performs pre-submission diagnostics on loan dossiers to prevent bank rejection:
  - **Audit Readiness Score (0-100%)**: Visual health meter of application strength.
  - **Mandatory Document Checklist**: Verifies Caste/Category Certificate, Income Certificate, Udyam Aadhar registration, detailed machinery quotations, bank statements, and premises lease deeds.
  - **Risk Flag Detection**: Alerts if project cost breaches statutory ceilings, if borrower age violates limits, or if promoter equity falls below mandated thresholds.
  - **Clear Remediation Steps**: Actionable guidance telling the entrepreneur exactly what to fix before filing.

### 4. 📄 Bankable Detailed Project Report (DPR) Generator
- Bridges the consultant cost barrier by automatically constructing bank-ready project proposals.
- **Financial Architecture**:
  - Executive Summary & Promoter Background
  - Enterprise Profile & Industry Classification (NIC Code)
  - Cost of Project: Capital expenditure, machinery, electrification, pre-operative costs, and 3-month working capital.
  - Means of Finance: Promoter Contribution, Concessional Bank Loan, and Expected Government Subsidy.
  - 3-Year Financial Projections: Projected Revenue, Cost of Goods Sold, Operating Expenses, Net Profit Margin, and **Debt Service Coverage Ratio (DSCR)**.
  - Break-Even Analysis & Sensitivity Metrics.
- **1-Click PDF Export**: Uses client-side `html2pdf.js` with dedicated print media queries to export structured, multi-page, formatted PDF dossiers ready for bank loan officers.

### 5. 🧮 Concessional Loan & EMI Calculator
- Real-time financial simulator tailored to government financing schemes:
  - Automatically calculates **Promoter Margin Money**, **Government Subsidy**, and **Net Borrowed Principal**.
  - Computes monthly EMI, total interest, and complete multi-year repayment schedule.
  - **Special Concessions**: Supports interest rebates (e.g., 0.5% - 1.0% interest rebate for women entrepreneurs under NSFDC/Stand-Up India schemes).

### 6. 📍 State Channel Partner Locator
- Interactive directory of authorized Channel Financing institutions:
  - **State Channelizing Agencies (SCAs)**: State-level corporations directly nominating beneficiaries for apex corporations.
  - **Public Sector Commercial Banks (PSBs)**: Partner banks disbursing composite credit.
  - **Regional Rural Banks (RRBs)**: Expanding access to remote and peri-urban entrepreneurs.
- Instant filtering by State, Union Territory, and Institutional Type with contact details and nodal officer designations.

### 7. 🤖 Context-Aware AI Scheme Assistant
- Natural language scheme advisor understanding queries in **English, Hindi, and Hinglish**.
- Grounded in the user's active entrepreneur profile to provide personalized eligibility answers.
- Explains documentation requirements, application stages, grievance escalation, and government subsidy disbursement protocols.

### 8. 👤 Entrepreneur Profile Engine & Demo Presets
- Central profile store that instantly propagates state changes to every tool in the application.
- Includes 5 diverse **Demo Presets** for instant hackathon evaluations:
  1. **Dalit Youth Tech Startup** (SC, ₹25 Lakhs, Maharashtra)
  2. **Rural SHG Handloom Artisan** (OBC Women, ₹5 Lakhs, Uttar Pradesh)
  3. **Scheduled Tribe Organic Agri-Producer** (ST, ₹10 Lakhs, Madhya Pradesh)
  4. **Divyangjan Retail Enterprise** (PwD, ₹3 Lakhs, Karnataka)
  5. **Women Micro-Food Processing Unit** (Women OBC, ₹8 Lakhs, Tamil Nadu)

## ⚡ Quick Start & Installation

### Option A: 1-Click Unified Windows Launcher (Recommended)

Double-click **`run.bat`** in the project root directory.

The script automatically:
1. Creates a Python virtual environment (`backend/.venv`) if missing.
2. Installs required Python backend dependencies (`pip install -r backend/requirements.txt`).
3. Installs frontend npm dependencies (`npm install`) if missing.
4. Starts the **FastAPI Backend** on port `8001`.
5. Starts the **React + Vite Frontend** on port `5180`.
6. Opens your default web browser to `http://127.0.0.1:5180`.

To stop all servers cleanly, double-click **`stop_servers.bat`**.

---

### Option B: Manual Step-by-Step Setup

#### 1. Clone the Repository
```bash
git clone https://github.com/Sher212/entre-help.git
cd entre-help
```

#### 2. Backend Setup
```bash
cd backend
python -m venv .venv

# Activate virtual environment
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8001 --reload
```
* Backend will be accessible at: `http://127.0.0.1:8001`
* Interactive API Documentation (Swagger UI): `http://127.0.0.1:8001/docs`

#### 3. Frontend Setup
In a new terminal window:
```bash
cd frontend
npm install
npm run dev -- --host 0.0.0.0 --port 5180
```
* Open `http://127.0.0.1:5180` in your web browser.

## 🔌 API Reference & Endpoints

All backend endpoints are prefixed with `/api`.

### System Health
| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/health` | Returns server health status, active modules, and version |
| `GET` | `/debug` | Returns active directory, scheme counts, and runtime info |

### Government Schemes
| Method | Endpoint | Description | Query Parameters |
|---|---|---|---|
| `GET` | `/api/schemes/search` | Search & filter schemes with match scores | `query` (string), `category` (string) |
| `GET` | `/api/schemes/{id}` | Get complete detail for a specific scheme | Path parameter: `id` |
| `GET` | `/api/schemes/categories`| List all scheme categories | None |

### Entrepreneur Profile
| Method | Endpoint | Description | Payload |
|---|---|---|---|
| `GET` | `/api/profile` | Retrieve currently active profile | None |
| `POST` | `/api/profile` | Update entrepreneur profile attributes | `EntrepreneurProfile` JSON object |
| `GET` | `/api/profile/presets` | Get 5 pre-configured demo profiles | None |

### Loan & EMI Calculator
| Method | Endpoint | Description | Payload |
|---|---|---|---|
| `POST` | `/api/loan-calculator/calculate` | Compute margin money, subsidy, EMI, and interest | `LoanCalculationRequest` (project_cost, subsidy_pct, interest_rate, tenure_years, is_woman) |

### Channel Partners
| Method | Endpoint | Description | Query Parameters |
|---|---|---|---|
| `GET` | `/api/channel-partners/search` | Search authorized SCAs, PSBs, and RRBs | `state` (string), `partner_type` (SCA, PSB, RRB) |

### AI Scheme Advisory Chatbot
| Method | Endpoint | Description | Payload |
|---|---|---|---|
| `POST` | `/api/assistant/chat` | Context-aware natural-language advisory query | `ChatRequest` (message, profile_context) |
